# HACA | Sales Performance Dashboard - Executive Performance & Conversion Analysis

**Batch: DA14 | Name: Zanoobiya M**

## Project Description
Developed an interactive Sales Performance Dashboard in Power BI for HACA to analyze leads and sales performance.

The dashboard shows key metrics like Total Leads (1K), Converted Leads (384), Conversion Rate (38.40%), Pending Leads (278), Avg Response Time (134.80 mins) and Avg Follow-up Counts (3.83).

It includes charts for Sales Executive Performance, Monthly Leads & Conversions, Conversion Rate by Executive, Lead Source Distribution, Course-wise Admissions, Lead Status and Response Time vs Conversion Rate.

Slicers for Month, Sales Executive, Course and Lead Source are added for easy filtering and to track executive performance and improve conversions.
